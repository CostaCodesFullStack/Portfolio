# 📋 Guia de Uso dos Currículos

Criei **3 versões diferentes** do seu currículo, cada uma otimizada para um propósito específico:

---

## 📁 Arquivos Criados

### 1️⃣ `CURRICULO_LINKEDIN.md`
**📝 Currículo Completo em Markdown**

**Para que serve:**
- Visualização completa e detalhada do seu perfil profissional
- Pode ser convertido para PDF usando ferramentas online
- Ótimo para compartilhar em repositórios GitHub
- Serve como referência principal do seu histórico

**Como usar:**
- Abra o arquivo no GitHub ou em qualquer visualizador de Markdown
- Para converter em PDF: use sites como `markdown-pdf.com` ou `dillinger.io`
- Mantenha este arquivo atualizado como seu currículo mestre

---

### 2️⃣ `LINKEDIN_RESUMO.txt`
**💼 Versão Otimizada para LinkedIn**

**Para que serve:**
- Conteúdo específico para cada seção do LinkedIn
- Formatação adaptada para o limite de caracteres de cada campo
- Palavras-chave otimizadas para SEO do LinkedIn
- Dicas de como melhorar seu perfil

**Como usar:**

#### **Passo 1: Editar Perfil no LinkedIn**
1. Acesse seu perfil no LinkedIn
2. Clique em "Adicionar seção ao perfil" ou nos ícones de edição ✏️

#### **Passo 2: Copiar Conteúdo Seção por Seção**

**📌 CARGO (Headline):**
```
Editar perfil → Cargo atual
Copie: "Estudante de Engenharia de Software | Desenvolvedor Web | React, Next.js, TypeScript"
```

**📌 SOBRE (About):**
```
Editar perfil → Sobre
Copie o texto da seção "SOBRE" do arquivo
Limite: 2.600 caracteres
```

**📌 EXPERIÊNCIA (Experience):**
```
Adicionar posição → Cole cada experiência separadamente
Não esqueça de adicionar: título, empresa, datas, localização e descrição
```

**📌 EDUCAÇÃO (Education):**
```
Adicionar formação → Faculdade Anhanguera, Engenharia de Software, 2025-2029
```

**📌 LICENÇAS E CERTIFICADOS:**
```
Adicionar certificado → Cole informações de cada certificação
```

**📌 HABILIDADES (Skills):**
```
Adicionar habilidade → Digite cada skill listada no arquivo
Dica: Adicione até 50 skills para melhor visibilidade
```

**📌 PROJETOS (Featured):**
```
Adicionar projeto → Cole informações e links de cada projeto
```

---

### 3️⃣ `CURRICULO_PDF.md`
**📄 Versão Simplificada para PDF/Impressão**

**Para que serve:**
- Versão concisa e direta (ideal para 1-2 páginas)
- Formatação limpa para conversão em PDF
- Pronta para enviar em candidaturas de emprego
- Pode ser impressa para processos seletivos presenciais

**Como usar:**
1. Abra o arquivo em um visualizador Markdown
2. Exporte para PDF usando:
   - **VS Code:** Instale a extensão "Markdown PDF"
   - **Online:** Use `dillinger.io`, `markdowntopdf.com`, ou `md2pdf.netlify.app`
3. Ajuste margens e formatação se necessário
4. Salve como `Caua_Costa_Curriculo.pdf`

## 💡 Dicas de Ouro para o LinkedIn

### **📸 Foto do Perfil:**
- Use fundo neutro ou desfocado
- Vista algo profissional (não precisa ser terno, mas evite roupas casuais demais)
- Sorria naturalmente
- Enquadramento: do peito para cima
- Boa iluminação (luz natural é ideal)

### **🎨 Banner Personalizado:**
Crie um banner no Canva com:
- Seu nome em destaque
- Cargo: "Desenvolvedor Web | Estudante de Engenharia de Software"
- Ícones das tecnologias que você domina (React, JS, Next.js, etc.)
- Cores que combinem com sua marca pessoal

### **✍️ Resumo "Sobre":**
Já está pronto no arquivo `LINKEDIN_RESUMO.txt`, mas lembre-se:
- Primeira linha é crucial (aparece na busca)
- Use emojis com moderação (apenas 🎯 💼 🚀 🎓 📧)
- Fale na primeira pessoa ("Sou", "Desenvolvo", "Busco")
- Inclua call-to-action no final (seu e-mail e portfólio)

### **🔗 URL Personalizada:**
1. Vá em "Editar perfil público e URL"
2. Clique em editar ao lado da URL
3. Use: `caua-costa-dev` ou `cauacosta-webdev`
4. Isso fica mais profissional: `linkedin.com/in/caua-costa-dev`

### **🎯 Palavras-Chave (SEO):**
Inclua naturalmente no seu perfil:
- Desenvolvedor Web
- Frontend Developer
- React Developer
- JavaScript Developer
- Estudante de Engenharia de Software
- Next.js
- TypeScript
- Matão SP / São Paulo

### **📝 Formato de Experiência:**
Use bullet points com verbos de ação:
- ✅ "Desenvolvido portfolio com Next.js..."
- ✅ "Implementado animações com Framer Motion..."
- ✅ "Integrado APIs REST em tempo real..."
- ❌ Evite: "Responsável por desenvolver..."

## 🛠️ Ferramentas Úteis

### **Para Converter Markdown → PDF:**
1. **Dillinger.io** (gratuito, online) ⭐ Recomendado
2. **MarkdownToPDF.com** (gratuito, online)
3. **VS Code + Markdown PDF** (extensão gratuita)

### **Para Criar Banner do LinkedIn:**
1. **Canva** (gratuito) ⭐ Recomendado
   - Template: "LinkedIn Banner"
   - Dimensões: 1584 x 396 px
2. **Figma** (gratuito, mais avançado)

### **Para Foto Profissional:**
1. **Remove.bg** - remover fundo da foto
2. **Photopea** - editar foto online (alternativa ao Photoshop)

### **Para Verificar Perfil:**
1. **LinkedIn Profile Strength** (no próprio LinkedIn)
   - Meta: perfil "Excelente" (100%)
